Entry for make.fun's **"Sum up 22 November's world news in one image"** bounty ($100 in USDC) — see the [bounty page](https://make.fun/bounty/news-image-20261122).

A pure-stdlib Python program (`main.py`, Python 3.13, no third-party
packages, no network) that draws a newspaper front page summing up the
world news of Sunday, 22 November 2026 as a single 1024x1024 PNG.

## Run

```sh
python3 main.py
# writes $MAKEFUN_OUTPUT_DIR/entry.png (default /output/entry.png)
```

Deterministic: two runs write byte-identical PNGs.
